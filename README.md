# Regions of Tyria

Public repository for **Regions of Tyria** releases for [Nexus](https://raidcore.gg/Nexus). The source code is maintained privately (due to reading region, map and sector names from memory).

A beautiful area notification as you walk in and out of different zones!

[!(Preview)](https://github.com/agaertner/bhm-zone-display/assets/13819164/882f5b9d-d6f1-4159-8de3-2e0d0e1575a9.mp4)

## Download

Download `nxa-zone-display.dll` from the [latest release](https://github.com/agaertner/nxa-zone-display-public/releases/latest), place it in your Guild Wars 2 `addons` folder, and enable it in Nexus. (Recommended: Download from the Nexus library in-game.)
