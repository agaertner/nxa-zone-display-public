# Regions of Tyria

Public repository for **Regions of Tyria** releases for [Nexus](https://raidcore.gg/Nexus). This repository contains release downloads and public information; the source code is maintained privately.

A beautiful area notification as you walk in and out of different zones!

## Showcase

https://github.com/agaertner/bhm-zone-display/assets/13819164/882f5b9d-d6f1-4159-8de3-2e0d0e1575a9.mp4

The video showcases the original Blish HUD module. This Nexus port is an exact equivalent in behaviour and appearance.

## Download

Download `nxa-zone-display.dll` from the [latest release](https://github.com/agaertner/nxa-zone-display-public/releases/latest), place it in your Guild Wars 2 `addons` folder, and enable it in Nexus.
